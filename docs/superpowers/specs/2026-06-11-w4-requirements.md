# W4 需求清单(用户验收反馈,2026-06-11)

来源:用户首次真实使用新产品(真实 435 场数据)后的反馈。按优先级:

## 1. 全站中文化 + 样式统一(W4a)
- 用户截图实锤:历史·球局页 = "ROUND ARCHIVE / Rounds" 全英文 + 原生裸样式控件。
- 范围:球局、球场、报告、设置(含同步面板)、强弱分析内容区 —— 全部套 W1 设计语言(token/卡片/中文)。
- **强弱分析要重做而不只是翻译**:用户原话"这一页没看懂"。结论先行(你最该练 X)、白话指标名、按洞/按杆/问题三块重组,补 spec §5.2 的 GIR/球道命中率/开球偏置等派生指标(后端 courses[].teeDirection/approachMiss 已有数据)。
- 流程红线(已记忆):收尾前 Playwright 逐页截图(桌面+412px)人眼验收,范围外的丑也必须上报。

## 2. 距离全部显示为码(W4a)
- 用户原话:"所有的m都换算成码给我显示"。
- 现状不一致:PrepHoleCard 读数已是码(routeYardageReadout),但 LiveSandbox 读数/建议卡 carry、Club Stats median、到果岭输入框等是米。
- 规则:**后端/接口保持米制不动;纯显示层换算**(1m = 1.09361yd,整数码),输入框(沙盘到果岭)以码输入、提交前转米。单位后缀统一用「码」。

## 3. 实战开局流程:选九洞 + 选 Tee(W4b,学 Garmin 手表流程)
- 用户原话:"选好球场之后要再选哪个9洞,再选什么Tee,你学一下garmin启动新一局的流程,尤其是手表"。
- Garmin 手表开局参照:Play Golf → GPS 就近确认球场 →(18 洞设施)选九洞组合(如 A+B/C+A)→ 选 Tee(蓝/白/金/红,决定码数)→ 进洞显示 front/middle/back。
- Web 沙盘映射:选球场 →(单 gid 18 洞场)选前九/后九;(双九设施)course options 本身已按组合分列 → **选 Tee**(新):
  - 后端:prep/沙盘目前硬编码蓝 T(TeeLocations Sets 含 2);需要 prep 接口支持 tee 参数(枚举该洞 hole.json TeeLocations 的 Sets,按 Set 选起点,影响 route 起点与码数)。
  - 前端:开局向导式三步(球场 → 九洞 → Tee),手表式大按钮风格;选完进洞。
- 此项含后端改动,独立成 W4b PR。
