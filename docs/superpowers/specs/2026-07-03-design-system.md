# AI Caddie 设计系统与设计原则(手表 / iOS / Web)

2026-07-03 · 由三路 Fable 设计评审收敛(HIG 规范 · 配色实测 · UI/组件一致性)。配套统一 spec `2026-07-02-unified-tri-surface-spec.md`,设计相册见 funnel `/gallery.html`。

## 现状判断

**三端现在不是一套设计系统,是三个各自成立的方案。** 手表最成熟(暗底/大字/F.C.B 层级,和 Garmin S70 范式同构);iOS 是标准浅色 app,但打球屏丢了 Garmin 的核心(大字距离);Web 是工程师仪表盘(灰阶塌陷、无网格、后端配置泄漏)。三端"同一个东西"—— 洞图、球童卡、距离数字、成绩色 —— 没有一个长得一样。**把三端各截一张拼一起,陌生人应当三秒内认出是同一个产品;今天做不到。**

---

## 五条北极星

1. **手表是原点。** 打球面的设计语言从手表版**反推**到 iOS 实战屏,不是从 iOS 摊薄到手表。手表已打样成功。
2. **两种面,一套 token:打球=暗色玻璃,复盘=亮色纸面。** 打球面(手表全部 + iOS 实战/记分屏)强制暗色(OLED 阳光下高对比 + 对齐 Garmin 习惯);复盘/备战面(iOS 其余 + Web 全部)亮色纸面。所有颜色 token 双值(dark/light),同一 hue。
3. **数字是主角。** 每个打球屏有且只有一个主读数,主读数字号 ≥ 2× 次读数(Garmin 中间数原则);数字一律等宽(tabular figures)、中性色,**禁止用颜色区分前/中/后**。
4. **同物同形。** 洞图、球童卡、距离栈、成绩徽章、球杆 chip、步进器 —— 六个核心组件三端共用同一份字段表、同一配色、同一字形字典,只允许尺寸与交互方式随端变化。
5. **Garmin 语法,Apple 语感。** 打球范式(F/C/B 栈、成绩色标、实打 ±、大字模式、旗向红箭头)向 Garmin 对齐(降低 S70 用户迁移成本);控件、动效、可达性(动态字体、触达尺寸)按 Apple HIG。

## 一、色彩(全端实测校准过,带对比度)

### 品牌 / 动作绿(唯一的绿,白名单三处:主 CTA · 推荐 chip · 进行中状态点)

| Token | Light(iOS/web) | Dark(手表) |
|---|---|---|
| brand.primary | `#15803D` | `#30D158`(Apple systemGreen dark,同 hue 家族) |
| brand.tint(选中底) | `#DCFCE7` | `rgba(48,209,88,.16)` |
| brand.border | `#86EFAC` | — |

> iOS 现在的病是"品牌绿通货膨胀"—— 绿同时做 header 底/按钮/链接/选中/图表/选中球杆,灵魂时刻(球童推荐)反而不 pop,而且 caddie 表"推荐"chip 竟然用**蓝**。绿必须收进白名单;链接改 `#374151`+下划线、选中态改浅绿 tint、图表走中性+语义色。

### to-par 成绩色(全端一套,兼容 Garmin;**Par 用中性不用绿**)

| 语义 | Dark(黑底) | Light 文字 | Light chip 底 |
|---|---|---|---|
| ≤−2 老鹰 | `#0A84FF` | `#1E40AF` | `#DBEAFE` |
| −1 小鸟 | `#59B8FF` | `#2563EB` | `#EFF6FF` |
| Par | `#FFFFFF` 中性 | `#111827` | 无底 |
| +1 柏忌 | `#FFD447` | `#B45309` | `#FEF3C7` |
| +2 双柏 | `#FF9F0A` | `#C2410C` | `#FFEDD5` |
| ≥+3 | `#FF453A` | `#B91C1C` | `#FEE2E2` |

> 规则:**暖色=高于标准杆(越差越深),蓝冷色=低于,中性=平**,刻意避开绿(高尔夫用户红绿色盲不少 + 绿底地图上致命)。手表记分卡想完整对齐 Garmin 8 阶可在 +4/+5 加粉 `#FF6482`/紫 `#BF5AF2`;iOS/web 汇总三档封顶避免彩虹。**彻底移除 iOS 现在的粉红超杆 chip。** 现在同一个"+1"手表黄、iOS 粉、web 琥珀 = 三套矛盾语言,手表那套(=Garmin)是对的,其余换装。

### 球场地图色(course palette,唯一一套,三端共享)

| 元素 | 色值 | 备注 |
|---|---|---|
| 树/界外 | `#2C4A1E` | 最深 |
| 粗草 | `#436D2E` | 与球道拉开 ≥1.8:1 明度 |
| 球道 | `#5C8F3E` | 比现在压暗一档 → 白覆盖物达 3.7:1 |
| 果岭 | `#7FBF5A` | 比球道亮一档 |
| 沙坑 | `#E8D9A8` | 去饱和沙色,**不用琥珀警示色画沙坑** |
| 水 | `#3E9BFF` dark / `#2E86DE` light | 只做填充 |
| 打球线 / 落点 | `#FFFFFF` + **2px `rgba(0,0,0,.45)` 描边** | 无例外 |
| 选中目标 / 自定义点 | `#FFD447`(黄=选中,对齐 Garmin) | |
| 距离标注 | 白字 + 黑色 pill `rgba(0,0,0,.55)` | **禁止裸文字/裸点上图** |

> 实测暴的雷:白线/白圈压球道 **1.81:1**、target 屏橙色落点点压球道 **1.18:1(=隐形)** —— 户外强光直接看不见。三端现在还有**四套球场绿**(手表内部就漂了三套 + iOS 灰调 sage,且 iOS 球道 vs 粗草只有 1.44:1、普通人都分不清)。

### 功能语义(固定绑定,禁止挪用)

- **推荐** = brand.primary 实心 chip 白字(三端同);
- **警示/风险** = 琥珀 `#FFD447`(dark)/ 文 `#B45309` 底 `#FEF3C7`(light);
- **危险打法/错误** = `#FF453A` / `#DC2626`;
- **蓝**只保留两个岗位:**under-par 成绩** + **水域填充**(现在蓝同时干六份工:前沿距离/小鸟/球道率/蓝T/测距线/水);
- **Tee 色**(蓝白金红)= 物理色,仅以带描边小圆点出现在 tee 上下文,永不挪用;
- **灰阶** light:`#111827`/`#374151`/`#6B7280`(`#9CA3AF` 仅 placeholder);dark:`#FFFFFF`/`rgba(235,235,245,.6)`/`#8E8E93`。

## 二、排版尺度(锚定手表现状)

| 档 | watch | iOS | web |
|---|---|---|---|
| meta/caption | 13 | 12 | 12 |
| body | 16 | 17 | 14 |
| 组件标题 | 18 | 17 semibold | 16 |
| 屏/节标题 | 20 | 28 / 34 largeTitle | 20 节 / 28 页 |
| 数字 M | 26 | 32 | 32 |
| 数字 L | 44 | 56 | 40 |
| 数字 XL(主读数) | 76 | 64 | — |

- 字体:SF Pro / SF Compact + PingFang SC;大数字 SF Rounded,**必须开 tabular figures**(GPS 刷新时不抖)。
- 中文:正文行高 1.5 / 标题 1.3 / 数字 1.05;全角标点;中西文间距;**单位「码」固定为数字右侧 0.6em 小字后缀,永久废除「(码)」括号写法**。
- 大字模式(D1)= 手表数字档整体上移一级的一个 token variant,不另做屏。

## 三、间距 / 网格 / 形状

- 4pt 基网格;组件内 padding 8/12/16;卡间距 watch 12 / iOS 16 / web 24。
- **Web:12 栏 · max-width 1120 · gutter 24 · 主 8 栏 + 侧 4 栏**;侧栏项字号提到 14px。(现在 Web 无 max-width、卡片宽度随意、主页 60% 死白。)
- 圆角:sm 8 / md 12 / lg 16 / pill;卡片 watch 16 · iOS 12 · web 12;主 CTA 一律 pill。
- 按钮高度 watch 44 / iOS 50 / web 36;每屏 primary ≤1。
- **卡片:有边框就去阴影,有阴影就去边框**(Web 现在混用)。

## 四、六个核心组件跨端规范(每件一份,收益从大到小)

1. **HoleMap(最优先)**:单一几何管线 → 三端同 course palette + 同覆盖字形字典(球=白点1px深描边 / 旗=红旗 / 目标=白十字环 / 距离签=黑底白字圆pill带方向箭头 / 落点=按杆型色点+深描边)。iOS/Web 只是更大可交互,不许另起画法;**Web 备战逐洞的白底散点示意图废弃**,换同一渲染。(见统一 spec:洞图底图可用 Garmin 官方 raster 或我们自绘 v2,叠加层规则相同。)
2. **DistanceStack(前/中/后)**:后上·中大·前下,中间 2× 字号,标签灰、数字全白。用在:手表大字屏 · **iOS 实战屏头部(替换现在那个显"—"的小 stat 盒)** · Web 备战洞头。
3. **CaddieCard**:固定槽位与顺序 = 推荐杆 → 目标点 → 码数 → 打法档(护分/标准/进攻)→ 一句理由。手表=两行压缩、iOS=完整卡、Web=沙盘侧栏,**字段与词汇逐字一致**。概率类统一降级为风险档(低/中/高 + 色点),UI 不出裸百分比(D2/D3);低置信数据统一样式:灰字 + 「参考」徽章。
4. **ScoreChip**:相对标准杆徽章,统一 Garmin 色标 + 填充 chip;手表洞圈/记分卡、iOS 历史、Web 复盘全替换(Web 那两根绿蓝大色条废弃)。
5. **ClubChip**:命名唯一化 **「1号木/3号木/7号铁/PW」**(阿拉伯数字 + 杆型);选中=green 实心白字,未选=描边。收敛掉 iOS 中文数字杆名、手表「3木」缩写。
6. **Stepper(记分 +/-)**:以现 iOS/watch 形态固化尺寸与热区(≥44pt),Web 补记一局复用。

## 五、两条硬约束(可写进 CI)

1. **对比度**:地图上任何图形 ≥ 3:1、任何文字 ≥ 4.5:1(户外场景自查;现有 DesignSnapshotTests 产物可直接跑对比度脚本)。
2. **一个色相在同端最多两个语义,且不得跨越"信息/警示"边界。**

## 六、各端要修的(HIG + 视觉,按优先级)

**手表(系统级 + 无障碍,最急):**
- 打球屏**保留系统时间**(一场 4 小时,手表首先是表)· 设计 **AOD 常亮态**变体(黑底只留洞号·Par + 到果岭中距离)· 出一枚**表盘复杂功能**(进行中显示"第N洞·到果岭287")· **「放弃」改红色 + 二次确认** · **横滑换打法改竖向分页 + 表冠**(避开系统返回手势)· 成绩**不只用颜色**(加 ±杆数/图例,色弱可读)· 底缘教学文案改浮层几秒消失 · 记分/选点支持**表冠精调**。

**iOS:**
- **实战屏换 DistanceStack 头部**(距离是第一公民)· 支持**深色模式**(打球屏强制暗)· **动态字体**(stat 胶囊 AX 档改纵向堆叠避免溢出)· 选择控件用**列表勾号**不用圆圈 radio · "Unknown course"→「未命名球场」· 「保存本洞」固定为底部悬浮 · **洞图升级到手表同源渲染** · 顶层若坚持首页三件事,保证每二级页边缘右滑返回 + 进行中卡全局可达。

**Web:**
- **设置→后端配置整页门控进 owner 诊断**(最反 Clarity)· 备战/沙盘白底散点**换真实洞几何底图** · 控件 36–44px、正文 ≥14px · 加 **max-width 1120 网格**、补齐主页死白 · 图表给足高度(折线 ≥240px)、单样本不画满宽条 · fail-AA 的琥珀条/蓝块改深字或换色。

**跨端一句话**:先定 **to-par 色板** 和 **course palette** 这两张表(三端照抄),"像同一个产品"和一半无障碍问题就解决 70%。

## 七、落地顺序

1. 写 tokens(色/字/距/圆角,dark+light 双值)——一周内三端可引用;
2. **HoleMap 统一渲染 + 覆盖字形字典**(收益最大);
3. CaddieCard 呈现 schema 统一;
4. iOS 实战屏头部换 DistanceStack(单屏改造);
5. ScoreChip 全端换 Garmin 色标;
6. Web 上网格与字阶、词表清扫 + 设置门控。
