# Garmin 球场数据 → 三端产品功能 路线图

2026-07-03 · Fable 设计(基于数据字典 `2026-07-02-garmin-course-data-reference.md` + 统一 spec `2026-07-02-unified-tri-surface-spec.md`)

遵守已定铁律:**零成功率/零百分比、不做风、不做推杆级等高线、坡度补偿(实打)保留并扩展、洞图以官方精绘 raster 为底、离线优先、码 + 简体中文**。

**一句话结论**:第一档能马上捡的五件里,**三件本质是"正确性修复"而非新功能**(女士 par 丢失、多 tee 距离错算、海水障碍漏检);真正的新决策能力(任意点实打、果岭坡向、拐点目标)全部由已解密的高程网格 y 轴驱动 —— **数据侧零缺口,只欠工程**,而且基本都在 `inspect_courseview_release.py` 和 `course_prep.py` 两个文件半径内。

## 与已定 spec 的一致性

- 全程**零成功率/零百分比**(差点微分、Rating/Slope 是官方定义值不是概率)· 风不做(经纬度只留天气展示钩子)· 推杆级等高线不做(果岭只给坡向箭头+前后高差)· 实打按"已实现、扩到任意点/球位→旗" · 地图优先(一切叠加长在官方 raster 底图上,自绘图降为兜底) · 离线优先(raster 18 张 ~2.3MB 开局缓存、粗高程栅格随 course package、果岭坡向预计算) · 手表三层不破坏(新信息挂第二层选点/障碍/果岭屏和备战侧)。
