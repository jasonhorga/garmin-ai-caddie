## 1. 全局操控宪法

- **表冠旋转 = 当前屏唯一的连续轴。** 每屏只有一根轴:球道图=「沿洞往前走」、列表=滚动、计分=杆数、球童=打法档位。有意义的停点给触觉哒声;轴的位置永远在右缘可见(地图进度条 / 列表滚动条 / 档位点)。**表冠从不翻页、从不同时管两件事。**
- **点按 = 「问它 / 选它」。** 点内容问数字(点沙坑出前后距、点大距离数字切实际⇄实打),点列表行即选中即生效。点按从不暗中跳屏——会离开本屏的点按对象必须长得像按钮、写着字。
- **长按 = 大字模式,全 app 唯一含义。** 任何数据屏长按,主数字放大到整屏。不做「长按出菜单」(不可发现,且与大字冲突)。
- **拖动 = 移动屏上唯一可移动的实物。** 只在果岭上存在(拖旗杆)。**地图永不平移。**
- **横滑 = 翻页,永远只是翻页。** 顶层兄弟屏横滑切换;被推入的子屏从左缘右滑 = 返回(同一个「横向=位置移动」心智)。横滑永不做动作:不滑动删除、不滑动换打法。
- **竖滑 = 滚动,与表冠同轴**;从下升起的浮层下滑收起。竖滑不藏指令。
- **屏上按钮:每屏至多一个主按钮**,通栏放底部,只放提交类动词(保存 / 确认结束);外加带字的角落小状态标。有界小计数(推杆、罚杆)允许用大号加减片。

**四条不变量**
1. 一屏一轴。
2. **看数字必须表冠可达**,只有「管理球局」才允许必须触屏(湿手 / 手套时点按会失效,读数不能失效)。
3. 从哪进就从哪出。
4. **屏幕自己永不动**——不自动缩放、不自动跳洞;唯一允许的主动行为是「往上加一层浮层」(选杆浮层升起时借走表冠,收起归还;谁在最上层,表冠归谁)。

**返回机制(唯一)**:右推进来的屏往右滑出去(= 系统左上箭头);下面升起的浮层往下按回去。全 app 禁止自绘 ×/返回 按钮。

**菜单机制(唯一)**:Garmin 的 START 硬键 → 变成一个**固定方位**:翻页条最左的「球局」页。不占用任何手势、第一天就能自然发现、位置可肌肉记忆。

## 2. 分屏操控表

**球局顶层五页**(横滑互达,进出即翻页;全部支持长按=大字):

| 页 | 表冠轴 | 点按 | 拖动 |
|---|---|---|---|
| 球局(菜单,最左) | 滚动列表 | 行即入:计分卡 / 选洞 / 球杆统计 / 设置 / 结束本场 | — |
| 球童建议 | 打法档位(稳妥 / 标准 / 进攻,带哒声) | 点打法=定为本洞方案,喂给选杆默认与地图目标线 | — |
| **球道图(主页,居中)** | 沿洞行走轴:全洞 ⇄ 障碍停点 ⇄ 果岭 | 点障碍问前/后距;点草地自由测距;点大数字切实际⇄实打(会话内记住);点角落计分标(近果岭时浮现)→ 计分页 | 仅果岭:拖旗 |
| 计分(记这一洞) | 总杆步进(每格哒声,到 Par 加重;自动预填已侦测杆数) | 推杆/罚杆加减片;顶行「计分卡→」;底部通栏「保存」= 记分 + 进下一洞 + 弹回球道图 | — |
| 旗向指引 | **空**(全 app 唯一无轴屏——允许空,不允许含糊) | 无对象 | — |

**推入层**(从球局页或计分页进入,右滑返回,深度 ≤2):
- 计分卡(表冠滚洞,点洞行 → 洞详情:改分 + 本洞击球列表)
- 本洞击球列表(表冠滚杆,点一杆 → **复用同一个选杆浮层**改杆;底部「+ 补记一杆」)
- 选洞(表冠滚格,点洞 → 确认页跳洞)
- 球杆统计(表冠滚杆)
- 结束本场(「结束并保存」→ 确认页;「放弃」次级、再确认)

**开局向导**(线性推入,选中即前进,右滑回退):选球场(表冠滚,就近优先,点选)→ 选 9/18 洞(整屏大格)→ 选发球台(短列表)→ 直接落在第 1 洞球道图。不设「开始确认」,一切可用「放弃本场」反悔。

**浮层**(压在任意页上,借走表冠):
- **选杆浮层(击球检测)**:半屏升起,上半仍露出「球位→旗」的新距离。表冠滚球杆、推荐杆预居中带「推荐」标;点行=记入本洞;**放着不管约 8 秒 = 按推荐杆自动记入并标「自动」**(事后在击球列表可改)——手套天零触屏走完;下滑 = 误报不记。
- **确认页(只给不可逆三事:结束 / 放弃 / 跳洞)**:「确认」放在与触发按钮相反的位置,防连点误触。可逆操作一律不设确认。
- 第 18 洞保存后自动浮出结束确认(唯一主动浮出,可下滑收起)。GPS 不自动跳洞;人到下一洞而上洞未记分,地图角落浮出「记上一洞?」小签,点它去计分,不点就安静待着。

## 3. 导航总图

```
开局:选球场 → 9/18 → 发球台
              ↓
[球局菜单]—[球童建议]—[●球道图]—[计分]—[旗向指引]   ← 顶层横滑
    │                        │
    ├→ 计分卡 → 洞详情(击球列表)  ├→ 计分卡(同一屏)
    ├→ 选洞  ├→ 球杆统计  ├→ 设置  ├→ 结束本场
浮层(任意页上):选杆 / 确认
```

家 = 球道图,居中:左一下球童、右一下计分、两端是菜单与旗向。任何深处回家 ≤3 步;保存计分自动归位到下一洞地图。**表冠不参与翻页**(有意背离 watchOS 10 的竖排 TabView 风尚)——表冠在打球中太贵,不能花在导航上。

## 4. 一致性整改(定案)

1. **球童换打法:横滑 → 表冠档位。** 横滑必须留给翻页;打法本来就是一根轴上的三档。
2. **屏上 ∧∨ 循环钮全部删除**(Garmin 移植痕迹):循环目标/障碍/打法一律走表冠停点;屏上箭头只允许出现在有界计数加减片里。
3. **「全屏缩放/障碍/选点测距/果岭预览/实打」不再是独立屏**,全部收进球道图的轴位与点按对象。目的地从约 19 个收敛为:**5 页 + 6 推入 + 2 浮层 + 开局 3 步**。
4. **选中即生效统一**:所有列表点行即提交(球场/发球台/球杆/打法);「先选再按确认钮」样式废除。确认页只留给不可逆三事。
5. **保存语义统一**:录入屏 = 底部唯一「保存」显式提交,滑走保留已填但不进洞;浮层 = 超时按默认提交 + 下滑取消;禁止「滑走即静默保存」第三种样式。
6. **自绘返回钮清零;球局主页(hub)与菜单合并**为同一个最左「球局」页,消灭两个「家」。

## 5. 反模式(红线)

1. **关键数字不许「必须点按才能看到」。** 验收:雨天测试——只用表冠加一次大按钮,走完「看距离 → 选杆 → 记分」全程。
2. **屏幕不许自己动。** 不自动缩放、跳洞、定时切屏;抬腕回来必须是离开时的样子。
3. **不许一屏多小钮。** 一屏一个通栏主钮,加减片至少四分之一屏宽,角落标必须带字。
4. **不许隐藏手势。** 无双击、无两指、无滑动删除、无力度按压;每个手势都有几何可见的对应物。
5. **不许让球员「读」。** 三秒规则:抬腕三秒内主数字直射阳光下读清,文字全部降为次级;一屏只讲一件事。

> 新增任何屏,先答四问:**表冠的轴是什么?点按问什么?从哪进就从哪出吗?大字放大哪个数?** 答不齐,不上表。
