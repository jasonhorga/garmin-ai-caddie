# AI Caddie 三端统一 Spec — Watch / iOS / Web(2026-07-02)

> 产出方式:先修 1 个残留 bug(离线球童一杆一距离,PR #219),再对 **Watch / iOS / Web** 三端做**三模型独立评审 + 对抗**(Fable 5 xhigh · GPT-5.5 xhigh · Gemini 3.1 Pro),三家都真看四套图:我们的 Watch 20 屏重做、**Garmin Approach S70 手册 P07–P11 基准**、iOS 现状、Web 现状。本文是收敛后的最终 spec。
> 关联:[[watch-golf-redesign]]、`2026-06-22-apple-watch-golf-design.md`、`2026-06-20-r12-garmin-gap-analysis.md`(§实现状态盘点)。

## 0. 产品原则(先于一切,三端共同遵守)
1. **AI 球童 = 唯一差异点,只说可信判断,绝不说伪精确数字。** 输出 = 推荐杆 + 打法(稳妥/标准/进攻)+ **平均杆数**(Garmin S70 自己也用,见 P08=2.8)+ 可选散布 ±码。**零成功率、零概率。**
2. **单位全用码**(地理距离/球场列表可 km)。**界面全简体中文**,规避 Garmin 商标功能名。
3. **地图 = 真实球洞几何**(后端 `hole_render` 烘焙图)。抽象色块/白底圆点不可接受。
4. **打球面离线优先**:球场信号差是常态,球童端上可算或按场预取,洞几何开局前全量下载。
5. **只显示数据撑得起的东西**:没有 DEM/风/干净 clubId/足够样本前,不上 PlaysLike、球杆 ±、成功率(信任是本产品唯一护城河,挂问号的数字=训练用户不信任)。

## 1. 三端宪章
- **iOS + Apple Watch = 打球面。** 共用**一个打球内核**(§2)。**Watch = 主打球面**(一瞥/独立/腕上,S70 范式);**iOS = 在场控制台**(大图规划·改错分·看合并真相·媒体)+ 打球前后一切 + **纯 iPhone 用户手机单机打完整 18 洞**(watchless 不被孤儿化)。iOS **不是**追 Watch 一瞥性的"对等第二打球面"。
- **Web = 复盘 / 备战 / 统计 / 球包管理。不开、不打实时局。** 只读投影(看进行中的局)= **deferred,不 forbidden**。
- **后端 = 单一真相源**;**打球中 iOS↔Watch 用 WatchConnectivity 本地即时同步**,后端负责跨设备恢复/云备份 + Web 读模型。

## 2. 统一打球内核(三端最重要的地基 —— 缺它 UI 再统一也会分裂)
- **一个球童引擎 + 一个响应 schema**,三端各自渲染同一对象。像素已坐实现在有三套词汇(Watch 平均杆数+64% / iOS 风险0/1/3 表 / Web Safe94-Attack76)——这是**硬指令**要消灭。iOS 的**序数风险 0/1/3** 是正确形态(非概率),统一往它靠。
- **一个真几何洞图组件**:以 **Watch 烘焙的 `hole_render` 为基准**,iOS / Web **向它对齐**(方向是 Watch→iOS/Web,别搞反 —— 像素证明 Watch 图最好、iOS 平面、Web 抽象)。含统一**覆盖字形字典**(蓝=你/球位、白落点环、虚线到旗、黑底药丸数字)+ **语义色**(绿=推荐、琥珀=沙坑/警示、蓝=前沿/水、to-par 色板)。
- **一套球局事件词汇 + 逐字段权威**:开局/选Tee/切洞/记杆/记推/球道方向/罚杆/击球/改杆/结束。
- **冲突模型(收敛结论)**:**append-only 事件(击球/距离/位置)永不冲突**;**仅物化的每洞成绩会冲突 → LWW + 仅在 iOS 呈现「手表/手机改过」历史;Watch 永不弹冲突。**(比"洞上Watch优先/事后iOS优先"的时间规则更简单可推理;比主从不锁死补录;比纯 LWW 有可见历史。)
- **中文词表 + 单位规则**统一(见 §6 D10)。

## 3. Watch 规格(主打球面,对标 Garmin S70)
**三层信息架构(消除现在 洞图/球童/Zoom 职责重叠):**
1. **抬腕/AOD 层 = 前/中/后果岭大字**(恢复"大字")+ 当前杆一句话建议。这是 Garmin S70 的默认主屏(P08 561/544/527、P09 532/518/500,中间超大)+ 独立**大字模式**(P10 专章)。**最省电、最该一瞥的态**,砍掉后是真空。
2. **交互层 = 真几何洞图** + 测距/选点/障碍/果岭。
3. **深层 = 球童解释 / 记分 / 球杆数据 / 积分卡。**

**自动行为(v1 底线,不是集成细节):**
- **到下一洞台自动建议切洞**(可撤销);**走动时距离连续自动刷新**(这是 GPS 测距仪的定义,不是功能);**AOD/抬腕大字态**。**AutoShot 延后**(硬件/算法/行为模型不具备,v1 硬上=大量错杆)。

**记分触发模型(现在完全缺):** 到下一洞台自动弹「记上洞?」并**预填 par 或已录杆**;总杆/推杆用表冠拨(不是从 0 点 6 次);**球道方向只在 Par4/5 出**;全链路可跳过、可撤销、可改。

**交互原语(全局统一):** **表冠=缩放/微调 · 拖=平移 · 点=确认**。选点/测距/果岭态:默认拖地图粗定 + 末几码表冠沿目标线微步(手套/出汗防误触);屏上明示当前模式。

**砍 / 改:**
- **砍 18 洞计分环**(表圈尺度不可读、撞右缘表冠缩放指示器、与一划外积分卡重复;hub「+2」已够)。
- **删球童屏「上果岭 64%」**(成功率);保留平均杆数 2.8 + 稳妥/标准/进攻。
- **v1 砍「实打 ±8」PlaysLike + 球杆「245±18」的 ±**(无数据源;球杆只显示有干净样本的杆)。
- 障碍屏支持**多障碍轮**(表冠切,显「1/3」)+ **水障碍**(蓝、非琥珀、罚杆义不同)。
- 障碍射线**绑当前球童目标线**,不是固定绿心线。
- 「上一杆 200」改**击球后瞬态**或收进本洞击球屏,不常驻。
- 补**降级态**:GPS 冷启/漂移、离线球童、电量保护(真图 Canvas+GPS 耗电,矢量轻量层)。
- 菜单**按频次**排(记分置前)。
- 距离语义**定约**:中 = 旗(默认旗在中心);**拖旗后洞视图主数字跟随**(对齐 Garmin)。

## 4. iOS 规格(在场控制台 + watchless 独立打球)
- **当前洞屏改「地图优先」而非「卡片优先」**:`CurrentHoleView` 现在全是卡片、无地图,主距离 chip 还显「—/0」(打球屏果岭距离永不该空)。真球洞图做成打球主面。
- **`HoleImageMapView` 换 Watch 同款真 `hole_render`**(现在是平面绿多边形,比 Watch 还糙)。补障碍进/过、选点测距、果岭前中后 + 拖旗、路线/落点覆盖。
- **控制台能力**(Watch 做不了的全在这):任意洞改分、击球流水编辑(补/删/改杆/补罚杆)、**合并真相唯一呈现处**(手表连着吗?最后事件何时?冲突历史)、媒体。
- **watchless 手机单机整局**:GPS 记杆/切洞/记分全链路(Web 砍实时后 iOS 必须承接,否则纯 iPhone 用户被孤儿化)。
- **球童**:同一 plan 对象渲染,主内容先给「这杆怎么打/目标点/错哪边安全」再给理由 + 备选表;序数风险 0/1/3 保留。
- 与 Watch **逐字段对齐**:Tee(已确认 iOS 有)、球道方向、罚杆。
- **同步**:WatchConnectivity 本地即时推(切洞 + 最新一杆);后端最终一致管其余;可见同步状态。
- polish:「Unknown course」球场名未解析要修。

## 5. Web 规格(复盘 / 备战 / 统计,不打实时局)
- **复盘:补 2D 落点图**(移植 iOS `RoundShotMapView`,大屏最适合看散布/偏向)+ 杆序 + 决策 vs 实际对照 + 媒体串洞时间线。现在只有数字表 = 无法解释"为什么这洞打坏"。
- **备战 = 真几何逐洞预览 + 试算,不是文本卡也不是工程台**:
  - **用同一真 `hole_render` 逐洞预览**(现在备战/决策沙盘把球洞画成白底抽象圆点 —— 最大的屏配最烂的图,方向反了;大屏是唯一能真预览真实球洞的地方)。
  - 选场 → Tee + 你的球包 → 球童逐洞试算(打法 + 平均杆数,**零成功率**)→ 你在此场往绩 → 产出「每洞一句话策略」crib sheet **缓存到 iOS/Watch 备战卡被打球面消费**。
  - **砍决策沙盘的 逆风 m/s 手输 / 击球类型下拉 / Safe94-Attack76 成功率泄漏**(消费者备战不出现 m/s 手输)。
- **统计**:已强(趋势/得分构成/分布/下钻),只需与 iOS Charts **统一语义色 + 词表**。
- **补记一局**:保留 `RecordRoundPage` 骨架但**去掉浏览器 GPS 实时打球** → 改**赛后录入/修正**工具(服务复盘/数据清洗,不进现场状态机)。
- **设置去工程味(P0 反消费者)**:`设置→后端配置` 裸露 OAuth client_id/redirect/scopes、user_id/permissions、AI 引擎名(Gemini/NVIDIA NIM/Anthropic)、factsUsed、RDS + 一句没翻译的英文 → **owner-only 或删**(去工程味 #103-105 漏了这个 tab)。

## 6. 决策日志(D1–D10,三模型对抗后收敛)
- **D1 大字速览:恢复**,作为 AOD/抬腕态 + 独立大字模式(**非**滑动流里的对等屏)。三源(Garmin 手册 + Gemini + Fable + GPT)一致;之前砍是把"信息相同"误判成"功能相同"。
- **D2 成功率:全删所有百分比**(Watch 64% + Web Safe94/Attack76);保留平均杆数 + 序数风险词。
- **D3 假数据:v1 砍**(PlaysLike 无 DEM;球杆 ± 数据脏)。不带低置信标注(表小、大数字必被当真)。
- **D4 自动行为:v1 必须** 自动切洞 + 距离连续刷新 + AOD;**AutoShot 延后**。
- **D5 冲突:append-only 事件永不冲突 + 每洞成绩 LWW + 仅 iOS 呈现改动历史 + Watch 永不弹**(Fable 修正了自己 r1 的时间性权威表)。
- **D6 iOS 角色:在场控制台 + watchless 单机整局**(非对等第二打球面)。
- **D7 选点/测距:拖 + 表冠微步结合;全局统一 表冠=缩放/拖=平移/点=确认。**
- **D8 18 洞计分环:砍。**
- **D9 同步时延:WatchConnectivity 本地即时必须**;后端最终一致管其余。
- **D10 命名/词表:全改简体 + 规避 Garmin 商标名**(PinPointer→旗向指引;PlaysLike/AutoShot 同理);旗杆非旗桿、总杆;留「选点测距」弃「测量击球」、留「3号木」对齐 iOS 弃「3木」。

## 7. v1 底线 · 迁移清单 · 验收
**v1 底线(缺一不可):**
1. 统一球童引擎 + schema + 权威字段表 + 冲突模型(先做,否则三端继续分裂)。
2. 真几何洞图组件(Watch 基准)被 Watch + iOS 共用;Web 备战同 render。
3. Watch 达 Garmin 级:前中后大字 + 记分 + 切洞 + 距离刷新 + 离线可用 + 赛后同步 + WatchConnectivity。
4. 球童只说可信判断(砍成功率/PlaysLike/脏球杆±/AutoShot)。

**迁移清单:** 砍 Web 实时打球(改补记)· 补 Web 落点图 + 真 render 备战 · Web 设置 owner-only · iOS 当前洞改地图优先 + 换真 render · iOS 补 watchless 整局 · Watch 接真导航+实时数据 + 砍环 + 恢复大字 + 记分触发 + 自动行为 · 三端统一球童 schema/词表/色板。

**验收:** 端到端 iOS↔Watch 同步 · 离线打完一局 · 冲突测试(仅 iOS 见历史)· 三端球童输出一致 · 设计快照(Watch/iOS)+ e2e(Web)· GPS 弱网降级 · 18 洞完整回放 · 无任何百分比/成功率泄漏。

## 8. 显式不做 / 暂不做
成功率/概率 · PlaysLike(无 DEM,待高程数据)· 风(场上难估)· AutoShot(v1,待数据+误识别 UI)· 球杆 ±(待 clubId 清洗)· 挥杆节奏(Garmin 有,我们非核心)· Web 实时打球 · Web 只读进行中(deferred 非 forbidden)· 果岭等高线。
