# AI Caddie 用户手册 / 产品说明书

> 覆盖三端:**Web**(复盘 + 备战 + 统计)、**iPhone App**(打球当下的实战球童 + GPS 记分)、**Apple Watch App**(腕上记分 + 距离 + 球童)。
> 本文档随产品演进更新;末尾「实现状态」一节诚实标注「已落地 / 后续」。

---

## 1. 产品概览

AI Caddie 把你的 **Garmin 高尔夫数据**(球局、逐杆、球场几何)变成两件事:

1. **AI 球童**——打球当下,根据你的真实球杆距离 + 球位 + 球洞几何,给出**该用哪支杆 / 怎么打 / 预期杆数**(不给「成功率%」,因为那需要单独校准的模型)。
2. **数据统计与复盘**——把历史球局聚合成 GolfLive 式的成绩分析、频率、表现统计、各球场/球杆趋势,帮你看清强弱、针对性练习。

数据**只读自 Garmin**(见 §2),不存你的 Garmin 密码,owner 数据受 admin token 保护。

三端定位:
| 端 | 定位 | 何时用 |
|----|------|--------|
| **Web** | 赛后复盘 + 赛前备战 + 深度统计 | 在电脑/手机浏览器,赛前查球场、赛后看数据 |
| **iPhone** | 打球当下的「实战球童」+ 逐杆 GPS 记分 | 球场上,口袋里的球童 |
| **Watch** | 腕上快速记分 + 距离 + 一行球童 | 球场上,抬手就看,免掏手机 |

---

## 2. 数据来源与同步

- **唯一可取高尔夫数据的通道 = Garmin CN 网页会话 cookie**(官方 OAuth 读不到高尔夫数据,仅做可行性占位)。
- 同步**已全自动**:定时任务 + 自愈的 headless 浏览器在 cookie 失效时自动重新认证。
- 同步内容:球局记分卡、逐杆(球杆 / 距离 / lat-lon / 球位)、球场几何(prodgeometry 网格 + 障碍)。
- **球场几何门控**:每洞几何覆盖 = ready / partial / missing。地图、GPS 距离、前/中/后果岭、坡度、障碍都受此门控——几何缺失的洞优雅降级(只记分 + 文字距离),不报错、不显示假数据。

## 3. Web 端

底部导航:**活动 · 备战 · 统计**(+ 设置齿轮)。owner 模式额外有「诊断模式」开关(默认关)——把工程化信息(raw ref、来源面板、数据质量/置信度、几何调试)收起,给干净的产品视图;打开才显示,保留 owner 排数据/订正能力。分享给球友的链接自动是干净视图。

### 3.1 活动(历史复盘)
- 落地为球局列表 + 「开始一局 / 继续这局」。
- 点单场 → **本场复盘**:逐洞成绩、逐杆、记分卡、(诊断模式下)来源链。

### 3.2 备战(赛前)
- 按定位列附近球场,或搜任意球场。
- 选球场 → 逐洞预演:俯视图(球洞地图)、推荐路线、障碍水/沙区间、按你的球杆阶梯的策略、**前/中/后果岭距离**、**坡度补偿**。
- 起始 9 洞可选(前九 / 后九 / 全 18)。

### 3.3 统计(GolfLive 改版,R13)
统计落地页走**紧凑端点**(约 36KB,而非旧的约 11MB 全量),首屏快。窗口可切「全部 / 近12个月 / 近10场」。
- **成绩走势**:近场总杆 / 差点折线;均杆 / 差点 / 得分区间 / 帕或更好率 KPI(带「vs 全部」对比)。
- **成绩构成(7 维)**:老鹰 / 小鸟 / 标准杆 / 柏忌 / 双柏忌 / **+3** / **+4** 各占比(按洞)——GolfLive 式维度。
- **各杆型**:三 / 四 / 五杆洞均值 + 保帕率。
- **表现统计**:开球球道命中、攻果岭 GIR、推杆(场均推杆 / 三推)。
- **频率**:季度 / 年度 / 月度。
- **各球场 / 各球杆**:点进球场看各九洞组合 + 单场复盘;球杆按码显示区间(已清洗:合并大小写、剔除无球杆 Unknown 杆)。
- **报告**:AI 生成的趋势 / 球局 / 球场报告(诊断模式看供应方/模型 + 证据链)。

### 3.4 实战 / 球童(网页版)
- 决策沙盘:选球场 + 球洞,试算一杆(距离 / 球位 / 策略 稳妥·标准·进攻),出球童建议(球杆 + 打法 + 避开区 + 预期杆数 + 可接受偏向)。
- 完整工具页保留智能球童面板。

### 3.5 设置
- 同步与数据健康、Garmin 会话导入、订正(订正球杆/成绩/罚杆,即时回流统计)、(owner)球员管理、后端配置。

## 4. iPhone App

打球当下的实战球童。主流程:开始一局 → 逐洞 → 记分 → 结束。

### 4.1 实战屏(CurrentHoleView)
- **距离头**:到旗杆(码)+ **前 / 中 / 后果岭(码)** + **坡度补偿(±码)** + 本洞成绩。(果岭距离 / 坡度来自本洞 prep 几何,几何缺失则不显示。)
- **球洞地图**:俯视图 + 你的历史落点散布(owner)。
- **球童建议卡**:推荐杆 + 打法(稳妥 / 标准 / 进攻)+ 理由 + 避开区(沙坑/水域)+ 可接受偏向。点「看完整方案 / 换打法」切策略。
- **选球杆**:你的真实球包。
- **保存本洞 · 含定位**:用手机 GPS 记录落点(精度显示)。
- **本洞成绩**:杆数 / 推杆 ± 步进;「更多调整」收纳细项。

### 4.2 历史 / 统计(StatsView)
- 入口:球局主页「数据统计」tile。
- GolfLive 式呈现(与 Web 对齐):**成绩构成 7 维** + 成绩走势折线 + 各杆型 + **表现统计(球道命中 / 攻果岭 GIR + 开球偏向)** + 成绩分布 + 各球场(可下钻各九洞)+ 各球杆(按码)。

### 4.3 GPS 记分(浏览器 / App)
- 浏览器 Geolocation 逐杆记分页可手动 ingest 一局(真机浏览器即可验证,免 TestFlight)。

## 5. Apple Watch App

腕上设备,地图为底、信息悬浮、流程化。单位用码、深色。两种用法:
- **独立练习记分(standalone)**:手表自己开一局、逐洞记分、结束上传(离线优先,有同步队列)。
- **手机协调(companion)**:与 iPhone 一起,手机把当前洞的距离 / 球童 / 果岭 / 坡度推到手表。

### 5.1 交互模型(Apple HIG)
- **数码表冠 转** = 每屏功能(缩放 / 调杆 / ±分等);**按** = 系统回表盘。
- **侧边键** = 系统(不可改)。**触摸**:点选 / 左缘右滑返回 / 长按出菜单。
- (Apple Watch 没有上下硬件键——所有导航走表冠 + 触摸 + 屏上按钮。)

### 5.2 屏幕
- **HOME(球道图)**:后 / 中 / 前果岭距离(中=大、橙)+ 坡度补偿 ±码 + 一行球童;**18 洞环贴圆角矩形屏幕边缘**(1 号上方居中起、顺时针、顶部留缺口、当前洞高亮、已记洞按成绩着色)。
- **Map Detail**:基准位显示距离事实栏、真实球道图与成绩环；转动数码表冠进入全屏并连续缩放，放大态隐藏事实栏与成绩环，返回不会改动球局数据。
- **球童一行**:推荐杆 + 下一杆提示 + 打法 + 置信度。
- **记分**:大杆数 ±、推杆 / 罚杆步进、保存。
- **计分卡**:逐洞列表(洞 · Par · 成绩,按 par 着色),点洞跳转;顶部总 toPar。
- **选洞**:18 洞格,当前洞高亮。
- **菜单 hub**:纯文字(计分卡 / 选洞 / 结束本场 / 继续打球),S70 式。
- **结束小结**:总杆 / 到标准杆 / 推杆 / 球道命中 / GIR / 待上传；球道与 GIR 只统计明确记录，未知洞不算失误。
- **开始**:筛选历史/缓存球场 → 明确选择 9 洞或 9+9 洞组与 Tee → 下载或离线开局 / 恢复进行中的局；未打过球场的远端全库发现仍在接线。

## 6. AI 球童引擎

- 输入:你的真实球杆距离模型(中位数 + p10/p90 + 一致性 + 距离趋势)、球位、GPS、目标、球洞几何。
- 输出:球杆 + 打法(稳妥 / 标准 / 进攻)+ 预期杆数 + 避开区 + 可接受偏向 + 证据链。
- **不给「成功率%」**(需单独校准模型,刻意不编造)。
- 球杆模型已清洗:合并大小写变体、剔除无球杆(clubId=0)的 Unknown 杆、低样本归类。

## 7. 坡度与果岭距离(R13)

- **前/中/后果岭(F/M/B)** + **坡度补偿(PlaysLike)** 都用**现有 Garmin prodgeometry 网格**算,**无需 DEM**:网格 positions 是 3D 米制,第二维是高程;果岭面取最近球洞终点的连通分量,front/back = 离球位最近/最远顶点,middle = 质心;坡度 = 果岭高程 − 球位高程 → ±码。与地图 / 障碍同一份几何、同一「几何 ready」门控。
- Watch 独立球局在腕上 GPS 与果岭坐标可用时实时重算 **前/中/后**；暂时缺 fix 或坐标时诚实回退到已准备的果岭距离，不显示伪造的 `0`。
