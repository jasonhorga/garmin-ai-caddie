2 · 每洞落点

全屏 topo，和打球屏同一张图。每一杆一条白线、一个编号点，点的颜色是落点球位；标签写“一号木 221”（球杆 + 这一杆的码数）；果岭上一个“推 ×2”。顶部是这一洞的记分符号，底部一排 18 洞小符号，左右滑或点它换洞。

3 · 改杆（同一屏）

点右上“编辑”：编号点变大成拖柄。按住拖动带放大镜；点空白加一杆（插在选中那杆之后）；点一杆，底部出现这一杆的球杆（左右滑）、球位、顺序 ‹ ›、删除。推杆数和罚杆在底部直接改。点“完成”保存整洞。
