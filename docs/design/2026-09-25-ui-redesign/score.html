和现在的差别

页面现在新方案为什么
本洞记分推荐 = 手动“记一杆”的次数 + 固定 2 推；改的话要点“手动确认”走四步：总杆 → 推杆 → 开球 → 罚杆，每步一个 −/+ 计数器一屏：一排带记分符号的杆数（○ 小鸟、□ 柏忌……）可以左右滑，推杆用分段按钮，开球画成三块小球道图，罚杆用小的 −/+；总杆和推杆按手表测到的挥杆预先选好：在果岭外的挥杆算一杆，在果岭上的算推杆，顶上画出每一次挥杆；推杆没测到就按上果岭时离洞的距离估，虚线表示“估的”；没有手表数据就用手机“记一杆”的次数 + 2 推；什么都没记就默认标准杆（Par−2 杆上果岭 + 2 推）建议对的时候还是一下保存；要改的时候不用翻四页，也不会漏改某一项
开球结果三个文字按钮“偏左 / 上球道 / 偏右”，下方一行说明三块小图：球道在中间，球落在左边、中间或右边。按第二杆的 GPS 位置和球道边界预先选好一块，标“GPS”，右上写原因（如“第二杆在球道右边 12 码”）；没有第二杆位置就不预选看图就懂；大多数时候不用动手。GIR 和推杆都没法靠 GPS 判断，所以不单独记，GIR 用总杆和推杆推算并标明；Par 3 自动隐藏
计分卡洞 / Par / 成绩三行表格，总分在底部单独一块，操作区一块卡片顶上大号的“+4”，下面一条每洞累计走势，前九、后九各一张卡，带 OUT / IN 小计；操作放底部先看到最想知道的“现在几杆、比标准杆多几杆”，走势一眼看出哪几洞丢了杆
结束本场入口主屏菜单里计分卡底部“结束本场…”新主屏去掉了菜单，结束本场本来就和成绩有关
本场汇总“+6”和杆数一张卡、推杆 / 球道 / 罚杆三张小卡、三个按钮全屏，和赛后复盘页同一版式：大号“+6”，记分卡（点成绩看落点），球道命中 / GIR / 推杆 / 罚杆四格打完就能看到和复盘一样的东西，保存后无缝变成复盘页；补上了 GIR
同步状态汇总页写“本场记录已同步”或“N 条记录将在结束前安全保存”不显示。点“保存并结束”后 App 自己先存本地、再在后台上传，没网就排队，有网自动补传用户对上传状态做不了任何事，不该拿它来打扰
