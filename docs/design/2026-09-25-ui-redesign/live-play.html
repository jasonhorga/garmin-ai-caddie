右上：到果岭 前 / 中 / 后和 Garmin 手表一样竖排。“中”44pt，是全屏最大的字；前后 14pt。
右下：记一杆全屏唯一的实心按钮，76pt，放在右手拇指最容易按到的位置。每洞要按 4–6 次。
左下：记分60pt 毛玻璃圆按钮。每洞按一次，打开记分面板，同时完成本洞。
左侧：障碍、打法、回到46pt 毛玻璃按钮，按需使用。“回到”只在你拖动或缩放过地图后出现。
障碍：一次看一个，和现在一样默认不显示。点“障碍”或直接点地图上的沙坑、水，只显示这一个：红色轮廓，前、后沿红点和“前 / 后”码数。底部中间出现一条小障碍条，写名称和“2 / 4”，‹ › 切换。
地图本身：推荐打法、目标点、果岭路线和每杆落点直接画在图上；点地图设目标点。这些都不需要按钮。
果岭：不画圈，只有一面旗默认果岭上什么都不加。果岭上只有一面旗，在旗位上（没设时在果岭中心）。点果岭进入现有的“调整旗位”界面：旗子到果岭前、后、左、右四条边各拉一条细线，线头标码数，拖动时实时变化，下方卡片也列出这四个数；拖旗子不弹放大镜（免得挡住上方的码数），旗子保持在手指上方不被挡住，果岭可以双指放大；回来后右上角多一行“旗 N”。
逐项决定

哪些必须、放哪、多大、什么样

元素去留位置大小样子理由
到果岭 前/中/后常驻右上角中 44pt 半粗；前后 14pt；框宽 92pt竖排，毛玻璃圆角框打球时看得最多的数字。放右上，不挡发球台到果岭的中线
记一杆常驻右下角76pt 圆唯一的白色实心按钮，“＋”加字最高频的操作，单手拇指可达；球洞在发球台一端最窄，右下角通常是空的
记分 / 完成本洞常驻左下角60pt 圆毛玻璃，旗子图标加“记分”每洞一次。和记一杆分两边，避免误触
洞号 · Par · 码数 · 本场成绩常驻左上角，挨着返回洞号 30pt；其他 13–14pt无底框，文字带阴影只需要扫一眼确认，不必做成卡片
返回常驻左上角40pt 圆毛玻璃回到本场计分卡，“结束本场”也放在那里，所以不需要单独的“…”菜单
推荐打法常驻，在图上地图上线宽 3pt；落点标签 13pt白色路线，落点处写“杆名 码数”，带球范围是浅色弧带球童建议直接叠在球场上，不占按钮和面板
障碍按需左侧按钮；选中后底部中间出现障碍条按钮 46pt；障碍条高 50pt，‹ › 各 32pt一次只显示一个：红色轮廓、前后沿红点、“前 / 后”码数小黑标签；障碍条写名称和“2 / 4”和现在线上的显示方式一致，只是从地图下的面板挪到了地图上。也可以直接点地图上的沙坑或水来选
切换打法按需左侧46pt 圆显示“1/2”，点一下换下一个大多数时候只看推荐的一个
回到当前位置按需左侧46pt 圆只在拖动或缩放后出现和地图 App 的习惯一样
果岭 / 旗位不要按钮点果岭—不画圈；一面小旗，在旗位或果岭中心点果岭进入现有的“调整旗位”界面（LiveGreenDetailView）：显示旗到前沿 / 后沿 / 左边 / 右边的码数（图上细线 + 卡片四格），拖旗子不弹放大镜、旗子保持在手指上方，果岭可 1–4 倍缩放；设好后右上角多一行“旗 N”
目标点不要按钮——单击地图直接设；按住目标点拖动，上方出现和现在一样的放大镜Garmin 的做法，少一个按钮；放大镜沿用现有 Touch Target 的样式
底部信息面板去掉———球洞是竖长条，两侧本来就空，信息放两侧即可
方案卡片去掉———路线和落点已画在图上，换方案用“打法”按钮
实现上要注意
缩放已经有了现有 HoleImageMapView 已支持双指缩放和拖动。新增的是：每打一杆自动缩放到“当前位置 → 果岭”，以及双击触发同样的缩放。
标注不跟着变大路线、文字和按钮在屏幕上保持固定大小，只有 topo 底图缩放，放大后也不会糊成一片。
毛玻璃的实现iOS 17 用 .ultraThinMaterial；iOS 26 以上可以换成系统的 Liquid Glass。
左手模式设置里一个开关，把左右两侧的控件镜像对调。
原型里的推荐打法、落点、障碍的“到 · 过”码数都是按图上比例估算的示意值，不是后端算出来的。这里是浏览器渲染，字体和毛玻璃效果和真机会略有差别。没有改任何 App 代码。
