The 7MB append test retains its strict `<8192` log-read byte assertion; its `<1s` elapsed
limit matches the user's responsiveness standard and only guards extreme degradation under
concurrent load. The byte assertion detects full replay or prefix rehash even if they finish
within the elapsed-time allowance. The index serialization format is unchanged.

`tests/perf/c138_append.py` measures actual HTTP latency and the server timing recorded by
production, including a cold first request, on 7MB/614 synthetic rows across 40 rounds. Optional
CPU pressure uses the production background gate and cooperative checkpoints. Its percentiles
are diagnostic evidence, not CI assertions. This does not bound uncooperative CPU work or the
time an already-running background unit takes to reach its next checkpoint. File bytes and
append order are checked independently of timing.
