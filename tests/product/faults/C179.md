# C179（含 C177）故障清单（J4.2）

所有条目测运行行为，不读取产品源码。让路/准入用例走真实 gate、真实 /prep 路由与 prep
single-flight、真实 stats warm / nearby / install pass 循环，只替换每个粒度内部的耗时活
（Event 扣住）；共享 CPU 池用例走真实准入与 `_IdleCpuPool`，线程池代替 forkserver 子进程；
X7 用真实 forkserver 子进程读 nice。

| mutant | 目标行为与判红 |
|---|---|
| 01-background-count-not-admission | 后台计数不参与准入：第二个后台单元与在跑的单元同时进门即红 |
| 02-yield-point-noop | 让路检查点变空操作：在跑单元在检查点不暂停，package 期间继续即红 |
| 03-prep-hole-no-yield | 冷 /prep 洞与洞之间不让：package 在途时第 2 洞照建即红 |
| 04-stats-phase-no-yield | stats warm 阶段之间不让：package 在途时下一阶段照跑即红 |
| 05-nearby-course-no-yield | nearby 预取场与场之间不让：package 在途时第 2 场照取即红 |
| 06-install-window-no-yield | 安装 pass 窗口边界（按 gid、向量种子前）不让：package 在途时下一 gid 照下即红 |
| 07-prep-gate-ignores-disconnect | 等 gate 时不查断开：客户端断开后线程仍等到 gate 截止即红 |
| 08-cpu-pool-no-foreground-reserve | 共享 CPU 池不给前台留子进程：前台冷渲染排在后台后面即红 |
| 09-background-geometry-bypasses-pool | 后台 prepare 几何下载不走共享几何池：并发 2、线程不在池内即红 |
| 10-background-geometry-unbounded | 后台下载不限一次一个：后台并发峰值 2 即红 |
| 11-nearby-batches-global | nearby 待处理批次退回全进程一份：另一玩家的批次被覆盖即红 |
| 12-omitted-tee-uses-package-tee | 不传 tee_box 时安装用包的 teeBox：安装身份与优先级和租约不一致即红 |
| M6-legacy-any-hole-exempt | 无 selection 的局任意洞都豁免：第 4/10 洞被豁免即红 |
| M7-allhole-exempt | 不带 holes 的整场冷 prep 豁免：holes=None/[] 被豁免即红 |
| M8-install-gid-only | 安装豁免只比 gid：同 gid 另一 tee/loop 的安装被豁免即红 |
| X3-background-placeholders-unbounded | 去掉后台占位上限 16：第 17 个后台 prepare 仍提交即红 |
| X4-startup-counts-background | startup_in_flight 把后台算进去：只有后台在途时仍报 True 即红 |
| X7-cpu-child-not-niced | 共享 CPU 池子进程不 nice：真实子进程优先级 < 父进程+10 即红 |

性能复测（「后台先起，200 ms 后来 package」与「后台 vector 在跑 + 前台冷 topo」）见
`tests/perf/c179_yield.py` 与 par1025/reply-C179.md，不设 CI 性能阈值。
