# J4 / 4.2: foreground package CPU isolation

The cold green and Garmin matte paths share the existing bounded topo process pool. Parent
threads retain cache ownership, downloads and responses. Exact bytes and warm-cache behaviour
are checked with synthetic geometry and JPEGs through real worker processes; no timing threshold
is asserted in CI.
