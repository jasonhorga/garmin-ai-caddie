# C112c navigation callback faults

J5.2 requires Back to reach the home with its resumable active-round card. J5.10 page freezing
must preserve the displayed hole's inputs and the live cursor. These mutations restore the
render-time decisions that can lag a synchronous first-stroke start.

All targets are native unit tests in `ProductLiveHolePageTests`, not UI tests. The fixture mounts
the real `RoundHomeView` with `[.startCourse(...), .hole(4)]` and a real `LiveRoundAppModel` /
isolated `OfflineStore`. A DEBUG-only probe retains the exact start and dismiss closures passed
to `CurrentHoleView` and the mounted home's path binding. No navigation rule is recreated by the
test. `withPrepSession` stops model background downloads before exercising local navigation.

| Mutant | Target test | Why execution reaches the changed line / expected behavioral failure |
|---|---|---|
| `C112c/01-dismiss-uses-rendered-live-flag.patch` | `test_j5_2_first_stroke_sheet_dismissal_replaces_prep_base_before_callback_refresh` | The mounted page's start closure calls the real `startRoundFromFirstStroke(4)`; the model and store now own the live round. The test does not settle/re-render before invoking that same page's sheet-dismiss closure. It calls `firstStrokeClubPromptDismissed` with the real path binding. The mutant reads the still-false `value.hasLiveRound`, leaves two routes, and fails the handwritten `[.hole(4)]` expectation. |
| `C112c/02-prep-uses-rendered-mode.patch` | `test_j5_10_started_round_stops_prep_following_and_persists_live_cursor_before_refresh` | After the real start, `prepPackage` is the GPS callback's production gate. The stale `isPrepMode` mutant returns a package instead of nil, failing before any navigation can be issued. |
| `C112c/03-cursor-uses-rendered-mode.patch` | `test_j5_10_started_round_stops_prep_following_and_persists_live_cursor_before_refresh` | The test then calls the exact dispatch method used by the deferred pager intent. The real store has a live round but the rendered prep flag is still true. The mutant calls `prioritizePrepHole`, whose model guard refuses live play, leaving activeHole=4 instead of 5. |
| `C112c/04-prep-uses-cached-package.patch` | `test_j5_10_prep_geometry_belongs_to_the_displayed_page_not_cached_package` | Before starting, the test retains the mounted page's package and replaces only the callback snapshot's package with another round. Calling the GPS gate must return the displayed package. The mutant returns the substituted package, failing the complete value comparison. |

The unstarted-dismissal and different-active-round cases protect against unconditional path
collapse and outgoing-page cursor writes. Existing hosted N=20 body-count, callback freshness,
selection, score-edit and drag-refresh tests remain unchanged.

Local Linux validation checks patch applicability and registered targets only. Native compilation,
the green unit run and killed-mutant results require the macOS CI runner; they have not been
claimed as local evidence.
