# Start Round: complete venues and Tee discovery (J4.1, J4.2, J5.1)

The recent catalogue retains at most **24 physical venues**, ranked by their newest played row
(date, round count, name). It returns every known sibling of each retained venue, including
unplayed CourseView/catalogue loops. The number of gid rows can exceed 24: one three-nine venue
plus 23 single-course venues returns 26 rows. Unplayed loops have zero rounds and no source refs.

backend (missing the third nine); native baseline failures are loading=false, retry=false and
three 180-second attempts instead of a single 25-second budget. No missing-API compile failure
is used as red evidence.
